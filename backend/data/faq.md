# Mistral Studio FAQ (demo knowledge base)

## Security
- SOC 2 Type II certified. GDPR compliant. EU data residency available (Paris region).
- Data encrypted in transit (TLS 1.3) and at rest (AES-256).
- SSO / SAML and SCIM provisioning on Enterprise plans.

## Hosting / data residency
- EU hosting in Paris (eu-west-1). Customer data stays in the EU.
- No training on customer data.

## Retention
- Configurable retention from 30 days to unlimited. Deleted on request within 30 days.

## Integrations
- Native connectors: Salesforce, HubSpot, Slack, Microsoft Teams, Google Workspace.
- Anything with a REST API via MCP connectors or custom agents.
- SAP S/4HANA via API + MCP connector.

## IoT security wrapper
- Wrappers enforce mutual TLS (mTLS) on every device, plus TLS 1.3 in transit and AES-256 at rest.
- Sensors publish over MQTT; the wrapper terminates and re-encrypts traffic at the gateway.
- Onboarding: bulk device certificate provisioning, zero-touch enrollment, per-device policy rules.
- Latest independent pen-test summary available under NDA; SOC 2 Type II report on request.
- Integrates with SAP ERP via REST API + MCP connector, or pass-through at the gateway.
